Java RapidAPI Taobao

O problema

Quem revende produtos importados precisa monitorar manualmente o que está em alta no Taobao — um processo lento e repetitivo que consome tempo que poderia ir pra atender clientes.

A solução

Uma ferramenta em Java que consulta a API do Taobao (via RapidAPI) e automatiza essa pesquisa de tendências.

Decisões técnicas

Optei por Java pela familiaridade com a linguagem e por controle mais direto sobre chamadas HTTP e estruturas de dados. O maior desafio atual é o gerenciamento de cache e limites de quota da API — cada chamada tem custo, então a ferramenta precisa decidir quando vale a pena buscar dados novos e quando reaproveitar resultados recentes.

Status e aprendizados

Projeto em desenvolvimento ativo. Tem me ensinado bastante sobre estratégias de cache, controle de rate limit e como projetar em torno das limitações de uma API de terceiros — problemas que exercício de curso não ensina.
